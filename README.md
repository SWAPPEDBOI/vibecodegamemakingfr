# make-game 키트 — 서브에이전트로 게임 만들기

## 이 폴더가 뭔가요?

Claude Code에게 **역할을 나눠 일을 시키는 실습 키트**입니다.
사람 한 명이 다 하는 대신, 4명의 전문가(서브에이전트)가 차례로 일합니다.

```
    나(오케스트레이터)
          │
   ┌──────┼──────┬──────────┐
   ▼      ▼      ▼          ▼
플래너 → 디자이너 → 코더 → 리뷰어
PLAN.md  STYLE.md  game.html REVIEW.md
```

이 순서를 **파이프라인**이라 하고, 파이프라인을 적어둔 설명서가 **스킬**입니다.
(= `.claude/skills/게임만들기/SKILL.md`)

## 쓰는 법 (3단계)

1. 이 `make-game-kit` 폴더를 **바탕화면에 통째로 복사**합니다.
2. 폴더 안에서 **터미널을 열고** `claude` 를 실행합니다.
   (폴더 주소창에 `cmd` 치고 엔터 → 검은 창이 뜨면 `claude` 입력)
3. **그냥 평소 말하듯이 부탁하면 됩니다.**

```
게임 만들어줘. 화살표로 움직이고 빨간 공에 닿으면 끝나는 피하기 게임.
```

"게임 만들어줘" 라는 말만 들어가면 Claude가 알아서 이 파이프라인을 실행합니다.
명령어를 외울 필요 없습니다.

> 정확히 시키고 싶으면 `/게임만들기 피하기 게임` 처럼 슬래시로도 부를 수 있습니다.
> `/` 만 쳐도 목록이 뜨니 거기서 골라도 됩니다.

끝나면 `games/<게임이름>/game.html` 이 생깁니다. **더블클릭하면 게임이 실행됩니다.**

## 폴더 설명

```
make-game-kit/
├─ README.md
├─ games/                      ← 만든 게임이 여기 쌓임
└─ .claude/
    ├─ agents/                 ← 전문가 4명의 "직무기술서"
    │   ├─ game-planner.md     기획: 무슨 기능을 만들지 정함
    │   ├─ game-artist.md      디자인: 색과 도형을 정함
    │   ├─ game-coder.md       코딩: game.html을 씀
    │   └─ game-reviewer.md    검사: 기준대로 됐는지 확인
    └─ skills/게임만들기/
        └─ SKILL.md            ← 파이프라인(순서) 설명서
```

`.claude` 폴더는 **그 폴더에서 claude를 실행할 때만** 적용됩니다.
그래서 반드시 이 폴더 안에서 실행해야 합니다.

## 주의 (토큰은 한정되어 있습니다)

- 한 번 실행에 에이전트가 4~5번 불립니다. **아무 생각 없이 여러 번 돌리지 마세요.**
- 게임은 `game.html` **한 파일, 200줄 이내**로 제한되어 있습니다.
- 기능을 잔뜩 요구하면 실패합니다. **기능 3~5개**짜리 아이디어를 주세요.

좋은 예: `공 튀기기`, `두더지 잡기`, `벽돌깨기`, `점프해서 장애물 피하기`
나쁜 예: `마인크래프트`, `온라인 대전 RPG`

## 직접 고쳐보기 (심화)

- 코더가 쓰는 문법을 바꾸고 싶다 → `agents/game-coder.md` 의 "코드 규칙" 수정
- 색을 6개 쓰고 싶다 → `agents/game-artist.md` 수정
- 검사를 더 엄하게 → `agents/game-reviewer.md` 수정
- 순서를 바꾸고 싶다 → `skills/게임만들기/SKILL.md` 의 "파이프라인" 수정

**전문가를 고치면 결과물이 바뀝니다.** 이게 이 실습의 핵심입니다.
